## 根因

Grim `Timer` 对每个非 duplicate flying 增加 50 ms。Rot-only 不含 position，不能成为 1.17+ duplicate，因此一次 placement 的 target/restore 被额外计为两个客户端 tick。Timer/Simulation setback 是坠落的直接上游原因；本会话没有 strict no-hit。

## 对照

- liquidSRC OnTick：同坐标完整 `PosRot(target) -> useItemOn -> PosRot(player)`。
- liquidSRC OnTickSnap：完整 target `PosRot`，随后 provider 保持 rotation。
